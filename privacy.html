Privacy policy

Last updated: October 12, 2026

whiteboard-yt is an internal tool used only by the owner of the YouTube channel Axel's Whiteboard. It has no other users.

YouTube API Services

whiteboard-yt uses YouTube API Services. By using whiteboard-yt you agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is handled according to this policy and the Google Privacy Policy.

Data accessed

  • Uploads: the tool uploads videos, thumbnails and captions to the owner's own channel.
  • Own-channel statistics: a private dashboard reads view counts and basic performance metrics of the owner's own videos.
  • The tool does not read, collect or store data about other users, viewers, comments or channels.
  • No data is sold, shared with third parties or used for advertising.

Storage and retention

  • All data is stored only on the owner's own computers at home; it is never sent to third-party servers.
  • The OAuth token is stored encrypted and is used only for the uploads and statistics above.
  • Statistics of the owner's own videos (e.g. views, likes) and metrics derived from them are kept for up to 36 months and then deleted.
  • Other data obtained from YouTube API Services (e.g. video titles) is refreshed or deleted within 30 days.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions (see also Google security settings). When access is revoked, the stored token stops working and is deleted, and all data obtained from YouTube API Services is deleted within 7 days. Deletion can also be requested at any time by email.
